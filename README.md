# Lectern v3

A course of lecture PDFs in, a trustworthy Anki deck out, made by cheap models.

This branch is the v3 rewrite. The shipping v2 app lives on `main`.

| Package | What |
|---|---|
| `packages/engine` | the headless engine: reads a course, makes and checks cards, sends them to Anki |
| `packages/app` | the Electron app around the engine |

Start with `docs/v3/brief.md`.
