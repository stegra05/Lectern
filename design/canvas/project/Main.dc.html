A key that lets me use an AI model

An API key is a long password from an AI company. With it, Lectern reads your slides using your own account, and the company bills you directly. One whole course usually costs less than one euro.

  1. Open aistudio.google.com and sign in with a Google account.
  2. Press Get API key, then Create API key.
  3. Copy the long code and paste it here.

The key works. It is kept in your Mac's keychain.
